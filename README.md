# Agro-Move

**AgriMove-Framework** is a modular, ROS 2-based toolkit designed for smart agricultural machinery. It provides high-level motion planning and AI integration for farming robots.

### Core Modules:
*   **PestSentry AI:** YOLO-based detection of pests and crop diseases.
*   **HydroSense:** Real-time soil moisture and nutrient analysis.
*   **Agri-Move:** Trajectory planning for harvesting and crop sorting based on MoveIt 2.

### Technology Stack:
*   **Framework:** ROS 2 (Humble/Jazzy)
*   **Planning:** MoveIt 2
*   **Simulation:** NVIDIA Isaac Sim
*   **Language:** Python 3.10+
